# Netflix Clone Website

## Overview

This project is a front-end recreation of the Netflix India landing page. It uses HTML to structure the page and links to a separate CSS file for styling. The page presents a hero section, streaming feature sections, frequently asked questions, and a footer.

> This is a learning project for front-end development. It is not an official Netflix website and does not provide real streaming, account creation, or sign-in services.

## Features

- Netflix-inspired landing page layout
- Navigation area with language and sign-in buttons
- Hero section with an email input and “Get Started” button
- Streaming feature sections for TV, offline downloads, watching on different devices, and kids' profiles
- Frequently Asked Questions section
- Footer with informational links
- Images and videos referenced from external Netflix asset URLs

## Technologies Used

- HTML5
- CSS3 (linked through `style.css`)
- External image and video assets

## Project Structure

```text
Netflix-Clone/
├── index.html
├── style.css
├── favicon.ico
└── assets/
    └── images/
        └── logo.svg
```

Make sure the `style.css` file and the referenced `assets/images/logo.svg` file are included in the repository. Other asset files may be needed depending on your implementation.

## How to Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `favicon.ico`, and the referenced assets in the expected locations.
3. Open `index.html` in a web browser.

For the best local development experience, you can open the folder in Visual Studio Code and use a local development extension such as Live Server.

## Notes

- The email field and buttons are visual front-end elements; the supplied HTML does not implement real membership, authentication, or payment functionality.
- Some images and videos are loaded from external URLs, so they require an internet connection and may change or become unavailable.
- This project is intended for educational and portfolio use.

## Learning Goals

- Practice semantic HTML structure
- Organize a multi-section landing page
- Connect HTML to an external stylesheet
- Build familiarity with common website sections such as navigation, hero content, feature blocks, FAQs, and footer
